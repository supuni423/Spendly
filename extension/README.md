# Spendly — extension (Phase 1: foundation)

Chrome MV3 extension scaffold: React + TypeScript + Vite, popup, content
script with a generic (schema.org/Open Graph) product detector, and a
background service worker. No backend calls are wired yet — "Analyze with
Spendly" currently returns a stub response.

## Develop

```bash
npm install
npm run dev
```

Then in Chrome: `chrome://extensions` → enable Developer mode → **Load
unpacked** → select `extension/dist` (run `npm run build` once first so
`dist/` exists; `npm run dev` rebuilds it on save via CRXJS's HMR).

## Try it locally

The content script is injected on demand (via the `activeTab` permission)
each time you open the popup — it never runs automatically on page load,
and there's no per-domain allowlist in `manifest.json`. Open any page with
Open Graph `product` tags or schema.org `Product` JSON-LD (the bundled
`test-page/index.html`, or a real product page) and open the popup;
Spendly reads that page's product on that gesture.

## Icons

`public/icons/icon{16,48,128}.png` are placeholders generated by
`scripts/make-placeholder-icons.mjs`. Replace them with exports of the
real artwork at the same filenames and sizes, then re-run `npm run build`.
